# ai-hub

## Project board

All work on ai-hub and ai-hub-demo is tracked in the GitHub Project "ai-hub":
https://github.com/users/cekinmezyucel/projects/2

- **Status:** Todo / In Progress / Blocked / Done. **Order:** the sequence we work in.
- Only one item is In Progress at a time.
- When work on an issue starts or ends, or it gets blocked, update its Status.
- Every new issue (in either repo, PRDs and bugs too) goes on the board with a Status and an Order.

```sh
gh project item-add 2 --owner cekinmezyucel --url <issue URL>
gh project item-edit --project-id <project id> --id <item id> --field-id <field id> --single-select-option-id <option id>
```

Get the IDs with `gh project field-list 2 --owner cekinmezyucel` and `gh project item-list 2 --owner cekinmezyucel`.
